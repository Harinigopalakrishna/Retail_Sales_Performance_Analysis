# Retail Sales and Inventory Analytics

## Project Overview
This project focuses on analyzing retail business data to understand sales performance, customer purchasing behaviour, product performance, and inventory status.

The project follows a complete data analytics workflow, starting from data cleaning and database management to exploratory data analysis, customer segmentation, and interactive dashboard creation.

## Project Objectives
- Clean and prepare retail datasets.
- Store and manage data using MySQL.
- Analyze sales and customer purchasing patterns.
- Perform customer segmentation using RFM analysis.
- Monitor product and inventory information.
- Create interactive dashboards to present business information.

## Tools and Technologies
- **Excel:** Data cleaning, formatting, PivotTables, and data preparation.
- **MySQL:** Database creation, data management, and SQL queries.
- **Python:** Data analysis, data visualization, and RFM customer segmentation.
- **Power BI:** Interactive dashboards and business reporting.

## Dataset Overview
The project uses retail business data containing information about:

- 1,445 Customers
- 1,615 Orders
- Order Items
- Products
- Brands
- Categories
- Stores
- Staffs
- Stock Information

## Project Workflow

### Phase 1: Excel – Data Cleaning and Preparation
- Organized and prepared the retail datasets.
- Checked missing values and duplicate records.
- Standardized data formats.
- Used Excel functions and PivotTables for data analysis.

### Phase 2: MySQL – Database Management
- Created and managed the retail database.
- Worked with primary keys and foreign keys.
- Used SQL queries, joins, grouping, and aggregate functions.
- Analyzed sales, products, stores, and inventory information.

### Phase 3: Python – Data Analysis and Customer Segmentation
- Connected Python with MySQL.
- Used Pandas and NumPy for data processing.
- Performed Exploratory Data Analysis (EDA).
- Created visualizations using Matplotlib and Seaborn.
- Applied RFM analysis to segment customers into Loyal, Regular, and At Risk groups.

### Phase 4: Power BI – Dashboard Development
- Created interactive dashboards.
- Developed KPI cards and different visualizations.
- Analyzed sales performance and customer segments.
- Included product, store, and inventory analysis.
- Used slicers, filters, and page navigation for interactivity.

## Key Outcomes
- Developed an end-to-end retail data analytics workflow.
- Performed customer segmentation using RFM analysis.
- Analyzed sales, products, stores, and inventory data.
- Created interactive Power BI dashboards for business reporting.
- Gained practical experience working with multiple data analytics tools.

## Conclusion
This project demonstrates the application of Excel, SQL, Python, and Power BI in solving retail business analysis problems. It provides practical experience in data preparation, database management, data analysis, customer segmentation, and business intelligence reporting.
